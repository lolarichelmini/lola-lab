# Lola Lab

Plataforma personal modular, instalable en el celular (PWA).

- **Shell:** `index.html`, `app.js`, `styles/` (tokens de diseño en `styles/tokens.css`).
- **Módulos:** cada uno en su carpeta dentro de `modules/` y registrado en `modules/registry.js`.
- **Contenido:** `content/` (episodios del podcast, tendencias).

Para sumar un módulo: crear su carpeta en `modules/` y agregar una entrada en `modules/registry.js`.
